# Chayan Watchlist

A responsive browser-based movie collection dashboard.

## Features
- Add Bengali, Hindi and English movies
- Store movie title, release year and uploaded poster
- Live per-language counters and total count
- Search and remove movies
- Local browser storage (data remains on the device/browser where it was entered)

## Deploy
GitHub Actions deploys the static site to GitHub Pages on pushes to `main`. Enable GitHub Pages with **GitHub Actions** as the build and deployment source in repository Settings if it is not already enabled.
